# C++ Programming Basics

My first-year C++ console programs from Eduvos (2024): weekly activities, practice questions, and test preparation. Each folder is its own Visual Studio project.

## What's inside

- **Weekly lessons and tasks**: `Week6`, `Week6 Task`, `week 5 task`, `Week 7`, `activity 8.1`, `activity9.1`, `activity10.1`
- **Practice and mock test questions**: `q11 Mock Test`, `q12`, `q13`, `Question11`, `testers`, `testerQ1`, `tester for Q2`
- **Assessment work**: `ITPPA - Formative Assessment ...`, `IndividualAct1`

## How to run

1. Open a project's `.sln` file in **Visual Studio** (with the *Desktop development with C++* workload installed)
2. Press **F5**
